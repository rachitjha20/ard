Three rules ARD follows

  1. Your file is never changed. ARD keeps its own copy. Every change is saved as a new version; the imported file and all earlier versions stay as they were.
  2. Nothing leaves this computer. No account, no upload, no usage tracking.
  3. ARD says what it actually did. If a result is a best guess (OCR, categories), or something could not be done exactly as asked (a font, a signature it cannot vouch for), you are told.

Getting documents in

  • Choose Import PDFs on Home or in the Library, or drop files onto the window.
  • Word, Excel, PowerPoint, OpenDocument and RTF files are converted to PDF as they are imported, if LibreOffice is installed. The layout can differ slightly from the original program.
  • Importing the same file twice does not create a second copy.
  • Password-protected PDFs can be imported and read. To change one, remove the protection first (Workspace → More).

Reading and finding

  • Inside one document: type in Find in document (or press Ctrl+F). Results appear in the side panel; click one to jump to the page.
  • Across all documents: use the search box in the Library. Each result shows the page where the words were found and opens there. Parts of words work, in any language.
  • Scanned pages have no text to find until you run text recognition; see Scanned documents.
  • Click a note or highlighted comment on a page to read it.

Changing pages

  • Actions apply to the page you are looking at. To act on several, select them in the Pages panel with Ctrl-click or Shift-click; the yellow label on the left of the bar shows what will be affected.
  • Reorder: drag thumbnails in the Pages panel.
  • Extract and Split create new documents and leave this one as it is.
  • Merge: in the Library, tick two or more documents and choose Merge.
  • More has reverse order, crop, insert pages from another document, watermark, and headers, footers and page numbers.

Editing and adding text

Change a line that is already there

  1. Choose Annotate, then Edit text.
  2. Click the line. ARD shows its text along with the font and size it detected.
  3. Change the text and choose Apply. Repeat for other lines, then choose Save as new version.

The original line is removed from the page and your text is drawn in the same place, size and colour. Font: ARD keeps the original font when it already contains every character you typed. A font stored inside a PDF usually holds only the characters that document uses, so if you type a character it lacks, ARD uses the closest standard font (same family, bold and italic) and tells you. You can also pick the font and size yourself.

Limits: one line at a time, Latin characters only, and other lines do not move, so a much longer line can run into what is beside it. Text that is part of a picture, or on a scanned page, cannot be edited this way.

Add new text

Choose Annotate, then Text, click where it should start, and type. Any language works; text outside the Latin alphabet is placed as a picture, so it looks right but cannot be searched.

Annotating

Choose Annotate. Nothing in the document changes until you choose Save as new version; until then you can Undo, Redo, move items (with Select) or delete them.

Becomes part of the page
Edit text, Text, Image, Stamp, Signature (a drawn picture of your signature).
Can be removed later
Highlight (select the text), Note, Rectangle, Ellipse, Line, Arrow, Draw. Remove them with More → Remove annotations.

Putting a shape or picture over text does not delete the text underneath. To remove content, use Redact.

Forms and signatures

  • Fill in a form: More → Fill in form. Values can be exported and imported (More menu) as a file.
  • Draw your signature: Annotate → Signature. This is a picture. It does not prove who signed.
  • Sign with a certificate: More → Sign with a certificate, using your .p12 or .pfx file. The file and its passphrase are used once and not kept.
  • Check a signature: Info panel → Check signatures. Valid means intact and from a signer this computer trusts. Unknown means intact, but ARD cannot vouch for who signed. Invalid means the document or signature was altered.
  • Changing a signed document creates a version in which the signature no longer verifies. ARD warns you first and keeps the signed version.

Protecting and redacting

  • Password: More → Password-protect. Only the password to open keeps the content private; “no printing” and “no copying” are requests that PDF programs are expected to honour. ARD cannot recover a forgotten password.
  • Redact: choose Redact, drag over what must go, then Redact and verify. The content under each box is removed, and ARD checks the result before accepting it.
  • Remove metadata: More → Remove metadata (title, author and similar).

Two things to know about redaction: a redacted page becomes a picture, so its remaining text can no longer be selected; and ARD keeps the earlier, unredacted versions, so share only the file you download afterwards.

Scanned documents

  • ARD marks scans that have no searchable text with Needs OCR. The Library has an album of them.
  • Open the document and choose More → Recognise text (OCR), pick the language, and start. It runs in the background; you can keep working.
  • The page pictures are not changed; an invisible text layer is added, as a new version.
  • Recognised text can contain mistakes. Info → Searchable text → Page details lists each page with a confidence score and marks the ones worth checking.
  • This needs Tesseract. Trust & Settings → Integrations shows whether it is installed and how to install it.

Organising the library

  • Categories are suggestions made from words found in the document, shown with a question mark until you confirm or change them. Use a card's ⋯ menu → Category. Your choice is never overwritten.
  • Tags: a card's ⋯ menu → Tags. Filter by tag with the Tag list.
  • Albums are the buttons under the search box: Recently added, Needs OCR, Unclassified, Large files and so on.
  • Duplicate candidates groups identical files, files with the same text, and files with very similar text. They are for you to review; ARD never deletes or merges anything by itself.
  • Documents are grouped by the month they were imported. Dates written inside a PDF are shown separately in the Info panel, because they can be wrong.

Undoing and going back

  • While annotating or redacting, Undo and Redo work on what you have not saved yet.
  • After saving, open the Versions panel. Any version can be downloaded, or made current again with Make current. History is never rewritten.
  • Move to trash hides a document; its files stay on disk. Restore it from the Trash view in the Library.

Getting documents out

  • Download (Workspace, top right) saves the current version as a PDF, as plain text, or as page images in a zip file.
  • Older versions are downloaded from the Versions panel.
  • Print opens the PDF in the browser's own viewer, which prints every page.

What ARD does not do

  • It does not reflow paragraphs. Editing text works one line at a time.
  • It does not convert PDFs to Word, Excel or HTML, or make a file PDF/A.
  • It has no AI features yet: no summaries, no questions and answers.
  • It does not scan for viruses and never calls a file “clean”.
  • It is for one person on one computer. It does not sync, share or back up.
  • Signature checks are offline, so a certificate that has been revoked is not detected.

Your documents are stored in ARD's data folder, shown under Trust & Settings → Appearance & diagnostics. Back that folder up yourself.
